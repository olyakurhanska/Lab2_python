# Лабораторна робота №2

Тема: Проектування та реалізація об'єктно-орієнтованих систем в Python з використанням класів і спадковості.

Виконані завдання:

1. task1.py - класова ієрархія, наслідування та поліморфізм.
2. task2.py - інкапсуляція та контроль доступу до атрибутів.
3. task3.py - магічні методи та перевантаження операторів.
4. task4.py - абстрактні класи та композиція.
5. task5.py - реалізація патерну Strategy.

Запуск програм:

python task1.py
python task2.py
python task3.py
python task4.py
python task5.py

Для запуску потрібен Python 3.

Усі програми використовують стандартні можливості Python і не потребують встановлення додаткових бібліотек.
